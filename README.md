# minthttp

Mint numeric http values, ranges, and human-readable units.

**Site:** https://theworker02.github.io/minthttp/

## Install / run

```bash
git clone https://github.com/theworker02/minthttp.git
cd minthttp
node src/cli.js
node --test
```
